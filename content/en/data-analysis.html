Keep the analysis layers distinct

A raw signal is not an identification, and an identification is not a concentration. A reliable analysis keeps those claims separate and preserves the evidence behind each transformation. This Guide follows a beginner LC-MS workflow; other experiments may use different coordinates and processing steps. All numerical examples below are hypothetical teaching data.

  1. Preserve and inspect: retain original files and sample records; check the acquisition and any conversion.
  2. Detect and link signals: find spectral peaks, follow them through time, and group appropriate signals into features.
  3. Match across runs: relate comparable features while retaining unmatched and ambiguous cases.
  4. Evaluate identity: test sequence, formula, structure, or library hypotheses using the available evidence.
  5. Quantify and compare: define the reported signal, inspect controls, and analyze the intended experimental comparison.

This is a map of responsibilities, not a mandatory software order. Identification-guided extraction and DIA workflows may combine steps. Ask what each output represents before joining tables or interpreting a plot.

Use open formats without losing provenance

mzML is a community format for spectra and acquisition metadata, not an identification-results table. HUPO-PSI maintains its specification. [1] ProteoWizard provides software for working with MS data. [2] Save the vendor originals, sample-to-file map, method, converter version, exact options, and processing log. A checksum helps detect a changed file; it does not establish that the experiment was valid.

After conversion, compare scan counts, MS levels, polarity, time range and units, precursor information, and representative spectra with the source. Document intended filtering. A successful file conversion is not proof that all needed information survived.

Profile, centroid, and feature are different layers

A profile spectrum records a peak's signal across multiple m/z coordinates. A centroid spectrum represents each detected spectral peak by a coordinate and intensity. These are data representations, not identification-confidence levels. [4]

Centroiding estimates spectral peaks and discards their full sampled shape. It is not simply a reversible file compression, a chemical identification, isotope grouping, or chromatographic integration. Its output depends on the algorithm and settings. A centroid intensity summarizes a spectral peak; it is not itself a time-integrated chromatographic area. ProteoWizard's peak-picking filter can use different algorithms and selected MS levels, so record these choices rather than treating every mzML file as equivalent. [5]

From peaks to a feature table

In an LC-MS workflow, a feature is a detected signal entity characterized by m/z, retention time, and an abundance measure, often with charge or isotope information. Software may link the same spectral peak across scans, delimit its elution peak, and group compatible isotope traces. The exact grouping and abundance calculation are method-specific. [6]

One compound can produce several features through different adducts or charge states. Conversely, unresolved species can contribute to one feature. An extracted ion chromatogram is a selected time trace; a feature assignment adds a detection or grouping model. Neither is automatically one identified molecule.

Alignment adjusts comparable coordinates across runs; matching proposes correspondences. Similar m/z and retention time support a match but do not prove identity. Inspect alternative matches and record tolerances. Keep the links back to the individual run and signal, including when a match or identification is transferred rather than observed directly. Results standards distinguish feature-level evidence from molecule-level summaries. [13]

Scores are not error rates

For a peptide database search, a peptide-spectrum match (PSM) relates an experimental MS/MS spectrum to a candidate peptide under specified digestion, modification, and tolerance rules. The top score is relative to that search space. Target–decoy methods use deliberately constructed alternative candidates to estimate incorrect matches under assumptions about how false target and decoy matches behave. Decoy construction, competition, and the reporting level matter. [3]

For a small molecule, mass agreement may support an ion or formula hypothesis without distinguishing structural isomers. Report what was compared: isotope pattern, product ions, retention behavior, or an authentic standard. For previously characterized compounds, the Metabolomics Standards Initiative's identified-compound category uses at least two independent, orthogonal properties matched to an authentic standard under the same conditions; library-only annotation is a different evidence level. Name the scheme used rather than treating a database name as proof. [7]

State which discoveries the FDR concerns

The false discovery rate (FDR) is the expected fraction of false discoveries among accepted discoveries, taking the fraction as zero when none are accepted. It describes a procedure over repeated realizations, not a probability attached to each result. A nominal threshold, an estimated FDR, and the unknown error fraction in one observed list are different quantities. [8]

State whether error control concerns PSMs, distinct peptides, proteins, or another defined set. Passing a PSM threshold does not automatically establish protein-level control or modification-site localization. Selecting a subgroup after filtering can change its error rate. Identification FDR also differs from FDR for tests of abundance differences; each needs its own defined question and procedure. [3]

Worked example: what does 1% mean?

Hypothetical repeated-analysis model: a procedure always accepts 100 results. With probability 0.5, none are false; with probability 0.5, two are false. Its FDR is 0.5 × (0 / 100) + 0.5 × (2 / 100) = 0.01 = 1%. A realized list has either zero or two false results, never exactly one. This constructed distribution illustrates the definition; it is not a target–decoy estimator or a claim about a real pipeline.

If a real report accepts 1,000 PSMs at a nominal 1% threshold, that threshold alone does not reveal the actual error count or certify every PSM as 99% correct. Check the estimation method, assumptions, reporting level, and whether the reported quantity is a threshold or an estimate.

An area ratio is an observation

Define whether the result is a peak height, integrated area, isotope/fragment sum, or higher-level summary, and state its units or arbitrary scale. An identification can be supported while its quantitative signal is interfered with; an unidentified feature can still have a reproducibly measured signal. Absolute concentration requires an appropriate calibration relationship and validation in the intended measurement context. [7]

Hypothetical ratio: analyte areas of 200,000 and 100,000 in samples A and B give A/B = 2. If an equal amount of a suitable internal standard gives areas of 100,000 and 50,000, the analyte/standard ratios are both 2, and their ratio is 1. This correction is justified only if the standard tracks the relevant unwanted response change. It does not demonstrate equal concentrations by itself, and one standard need not represent every analyte.

Normalization makes assumptions

Normalization adjusts measurements to a defined reference or comparability assumption. Common approaches use internal standards or a summary across many measured features. A median-based adjustment often assumes that most retained signals are stable, or that their changes balance. If most truly change together, that assumption can remove the effect of interest. Compare distributions and controls before and after the adjustment, and report the reference, feature set, formula, and processing order. A phosphoproteomics experiment demonstrates how centering can distort real directional changes; its alternative method is not a universal replacement. [9]

Hypothetical failure: reference areas [100, 200, 300] and test areas [200, 400, 600] have medians 200 and 400. Scaling the test by 200 / 400 makes the vectors identical. That is appropriate for an assumed twofold technical multiplier; it erases a genuine twofold global increase if that was the cause. The numbers alone cannot choose between these explanations. Normalization also cannot reconstruct a saturated or unacquired signal.

Quality control is part of inference

Choose controls and acceptance criteria for the question before inspecting the desired group separation. In untargeted metabolomics, mQACC recommends reporting how controls were prepared, placed in the sequence, and used to judge analytical performance. [11]

  • Blanks: investigate background or carryover according to the blank type and its position; a solvent blank does not test every sample-preparation contaminant.
  • Repeated pooled or reference QC samples: track analytical stability and drift for signals represented in that material. A pool can dilute rare, sample-specific signals.
  • Standards and suitability checks: test defined response, retention, or mass-performance expectations; a pass applies to what was actually tested.

Inspect mass error, retention drift, intensity, peak shape, missingness, and QC behavior against injection order and batch. Prespecify exclusions and document failures; do not remove samples merely because they weaken a preferred conclusion.

Batch structure and replication cannot be repaired by labels

Hypothetical confounding: if all controls are measured on day A and all treated samples on day B, a day effect and a treatment effect cannot be separated from those data alone. Plan suitable randomization and balance within practical blocks; preserve run order and batch metadata. Correction software cannot supply missing experimental comparisons. Reporting standards explicitly connect the design and acquisition schedule to analysis. [12]

Hypothetical replication: six independent biological samples injected twice give 12 injections, not 12 independent biological replicates. Technical repeats probe the repeated step; repeated injections do not assess independent extraction variability. Retain the sample hierarchy and model or summarize repeats appropriately. Paired subjects, preparations, and measurements should not silently become unrelated observations. [13]

A missing value is not automatically zero

A missing value means a particular result is unavailable under the pipeline's rules. Possible causes include low signal, an unselected precursor, failed detection or matching, interference, and a confidence filter. A measured feature without an accepted identity is different from a missing abundance measurement. A result table alone may not establish the cause. Original benchmarking across several proteomics workflows shows that imputation does not necessarily improve the downstream comparison. [10]

Inspect missingness by feature, group, batch, and run order, and revisit source traces where useful. State what was filtered, which values were estimated, and why the chosen model is plausible. Compare important conclusions under reasonable alternatives. Do not apply a blanket zero, minimum, mean, or random-small-number replacement. A missing-data method is an assumption about unobserved data, not a recovered measurement.

Hypothetical arithmetic: [100, 100, missing] has an observed-only mean of 100 using two values. Replacing the missing value with zero gives 200 / 3 ≈ 66.7 using three entries. Neither calculation establishes the unknown value or an unbiased group mean. A format can distinguish missing data from a reported zero; inspect the exporter rather than guessing. [13]

Leave an auditable path to the result

Keep raw and converted inputs, sample relationships, quality-control decisions, database or library releases, software and environment versions, scripts, parameters, and intermediate-to-final identifiers. Record random seeds when relevant and preserve the unmodified table alongside transformed or imputed versions. Report integration rules, normalization, missing-data handling, error thresholds, and exclusions. This extends the reporting standards' requirement to describe the analysis and validation sufficiently for others to examine it. [12]

Re-running the same inputs tests computational reproducibility. Agreement across independently prepared samples or experiments addresses additional sources of variation. Neither is guaranteed by using an open format.

Paths into advanced computation

  • Signal processing: peak models, isotope grouping, deconvolution, and alignment.
  • Identification: search-space design, spectral prediction, and confidence calibration.
  • DIA analysis: coordinated trace extraction and interference assessment.
  • Statistical learning: uncertainty, missing-data models, and evaluation on held-out experiments.

For prediction, keep the test set out of feature selection, fitted preprocessing, and model tuning. Split at the relevant independent unit: related injections or samples must not leak across a split intended to test new subjects or batches. Report the split, candidate set, metrics, and failures; a high score has meaning only within that design. [12]

Check your understanding

Does centroiding identify a molecule?

No. It changes how spectral peaks are represented. Feature detection and identity evaluation add different models and evidence.

Can a low FDR replace experimental quality controls?

No. Identification error control does not settle contamination, integration, quantification, batch confounding, or replication.

Should every missing value receive the same replacement?

No. First ask which result is missing, how the pipeline produced that state, and which assumptions suit the intended comparison. Preserve the distinction between measured and estimated values.
