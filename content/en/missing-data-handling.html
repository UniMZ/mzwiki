Start with the missing result, not the replacement

Missing-data handling is a sequence of decisions about unavailable measurements. This Guide starts after a feature table exists; use data analysis for the wider workflow. Decide whether the immediate goal is visualization, prediction, or estimating an abundance difference. A completed matrix convenient for a heatmap is not automatically suitable for a statistical test. All examples here are hypothetical.

Preserve the original table and a separate status mask. Distinguish a missing abundance, a rejected integration, an unacquired measurement, and a measured signal without an accepted identity. Check the export convention: zero may mean a measured number or a software placeholder. Do not convert every blank to zero, or every reported zero to missing, without checking its origin.

Build a missingness audit

Count observed values per feature and per independent sample, then separate those counts by condition, batch, and run order. Inspect whether failed samples have many unrelated gaps. Review selected source traces and controls, including borderline and well-measured cases, rather than only promising biological hits.

Separate re-extraction from imputation

First ask whether the source signal can support a defensible measurement. In xcms, gap filling integrates acquired signal in a feature's m/z–retention-time region and flags filled peaks. This is signal re-extraction, not statistical prediction of a missing table entry. [1] Review boundaries, alignment, interference, and background; an integrated region can contain noise or the wrong peak. Re-extraction cannot recover an acquisition that never happened. Keep its provenance distinct from both original detection and imputation.

Use mechanism labels as assumptions

The missingness mechanism describes how the probability of a missingness pattern relates to the full data. Rubin's framework distinguishes what is observed from what remains unobserved. [2]

  • MCAR, missing completely at random: missingness does not depend on observed or unobserved values in the modeled dataset.
  • MAR, missing at random: conditional on the observed information, the pattern's probability does not additionally depend on unobserved values. Dependence on a recorded batch can be compatible with MAR.
  • MNAR, missing not at random: dependence on unobserved values remains after conditioning on observed information. A tendency to lose weaker, unobserved signals is one plausible example.

These are not three shapes that a heatmap can diagnose. Associations with observed variables can challenge MCAR, but observed patterns alone generally cannot distinguish MAR from MNAR or establish either. Mechanisms can coexist, and the classification depends on which information is available. State the scientific and acquisition evidence supporting the assumption. The target quantity matters too; these labels do not prescribe one handling method. [3]

Calculate how replacement changes the answer

For Q, the observed control mean is (100 + 120) / 2 = 110; the treated mean is 220. The ratio of observed arithmetic means is 2. Consider two deliberately different replacement assumptions:

  • Replace the missing control with 110: the completed control mean remains 110 and the ratio remains 2.
  • Replace it with 20: the completed mean becomes (100 + 20 + 120) / 3 = 80, so the ratio becomes 220 / 80 = 2.75.

Zero replacement would instead give a control mean of approximately 73.3 and a ratio of 3. None recovers the unknown observation. Even unchanged means can hide altered variances and misleading certainty. These are arithmetic-mean ratios, not coefficients from a log-scale model. An observed-only calculation also needs assumptions; it is a comparator, not ground truth.

Choose an analysis that can represent uncertainty

  • Analyze available measurements: use an appropriate model only where the design and remaining observations support estimation. Record per-feature sample counts; dropping incomplete cases can select a different population.
  • Model censoring: if a justified reporting rule establishes that a value is below a known limit L, retain that bound. A continuous censoring likelihood uses the probability of being below L, rather than pretending L/2 was observed. Left-censored observations can be represented as intervals. [4] Generic missingness does not supply such a bound.
  • Impute explicitly: choose a model consistent with the intended analysis, plausible missingness, and sample structure. Neighbors or latent factors need informative observed relationships. Single replacement does not propagate missing-value uncertainty; multiple imputation requires suitable models and combination rules, not merely repeated random fills. [5]

For R, fabricating three small treated values and running an ordinary test can manufacture both an effect and its apparent precision. Consider a justified censoring or detection model, or report the comparison as insufficiently quantified. Benchmark evidence supports comparing downstream conclusions with an unimputed alternative, rather than choosing the method that creates the most discoveries. [6]

Keep evaluation and reporting honest

For prediction, split at the independent biological unit before fitting preprocessing. Within each training fold, learn imputation, scaling, and feature selection; apply the fitted operations to its held-out fold without using held-out outcomes. Fitting a data-dependent imputation model on the full dataset before splitting can leak held-out information. [7] Inferential imputation may appropriately include study-design variables, but its uncertainty must enter inference.

Repeat key comparisons under plausible handling choices and report changed directions, effect sizes, intervals, and retained feature sets. Randomly masking observed entries tests reconstruction of those entries, not necessarily real missing signals. Preserve masks, exclusion rules, parameters, seeds, and processing order alongside outputs. These details make the analysis inspectable. [8]

Check your understanding

Does lower reconstruction error guarantee better differential-abundance testing?

No. Reconstruction and valid inference are different goals. Evaluate effects, uncertainty, and error behavior for the intended task.

Can an all-missing group be called zero abundance?

No. Investigate acquisition and processing evidence. A missing table entry supplies neither an exact zero nor a known censoring limit.
