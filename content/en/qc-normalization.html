Measure unwanted variation before correcting it

Quality control (QC) asks whether the analytical system behaved acceptably for the intended measurement. Normalization changes a numerical scale using an explicit reference or assumption. Batch correction models systematic differences associated with processing groups or acquisition order. These activities overlap, but a cleaner-looking matrix is not proof that the measurements became more reliable.

Start with a proposed explanation: unstable response over injection order, different loading, or a discontinuity after maintenance. Ask what evidence could distinguish that explanation from real sample variation. A batch effect can affect features differently; one multiplier need not describe the whole experiment. The goal is a defensible comparison, not identical distributions at any cost.

Give each control a specific job

A system-suitability sample tests whether a method is ready to run. Blanks reveal background or carryover under the conditions they represent. Repeated pooled or reference QC samples track analytical consistency. An internal standard follows the response of a defined added substance. These controls answer different questions and are not interchangeable. The mQACC recommendations emphasize describing control composition, use, placement, and acceptance criteria. [1]

For a pooled QC, document which samples contribute and when pooling occurred. Reinjecting one prepared pool mainly examines variability after that preparation; separately processing pool aliquots also samples those processing steps. A component rare in study samples may be diluted below detection in a pool. Consequently, good pooled-QC behavior supports the signals the pool represents, not every possible analyte.

Choose QC placement and frequency from the method's stability and the variation you need to observe. A few controls at the start cannot describe an unobserved change halfway through a long sequence. Keep a stable reference across batches when cross-batch comparison matters. Record interruptions, maintenance, run order, and control identity alongside the measurement table.

Worked example: what a drift correction assumes

Constructed teaching model: a chemically stable QC gives response 100 at injection 1 and 80 at injection 11 for one feature. Suppose independent evidence justifies a linear multiplicative drift model over this interval. At injection 6 the interpolated expected QC response is 100 + (6 − 1) × (80 − 100) / (11 − 1) = 90. To express a study-sample response of 72 at that position on the injection-1 scale, calculate 72 × 100 / 90 = 80.

The corrected value is still a relative response, not a concentration. Two endpoints do not themselves establish a linear trajectory. A transient problem between them could be invisible, and a different feature may drift differently. Extrapolating beyond the observed interval adds another unsupported assumption. This arithmetic explains one correction; it does not recommend two QC injections or a particular spacing.

Wehrens and colleagues compared correction strategies on several untargeted MS datasets and found that performance depended on the data and available controls. [2] In practice, assess whether enough reliable QC observations exist to support the chosen model complexity and whether the controls represent the affected signals.

Choose the reference deliberately

Different denominators define different results. Signal per original sample volume, signal per cell, signal per total protein, and signal relative to a pooled reference are not synonymous. A change in the denominator can change the biological interpretation even when the numerator is measured perfectly. State whether a correction addresses analytical response, sample input, or a deliberately relative biological scale.

Distribution-based methods require assumptions about which parts of the measured distribution should remain stable. Median scaling is a simple example; forcing distributions to agree is a stronger constraint. In a phosphoproteomics experiment, Kauko and colleagues demonstrated how genuine broad directional changes can conflict with centering assumptions. [3] That is a reason to test assumptions, not to prohibit normalization or declare one alternative universally best.

Worked example: a correction can erase a real effect

Separate constructed example: four feature responses in sample A are [10, 20, 30, 40]; sample B has [20, 40, 60, 80]. The medians are 25 and 50, so scaling B to A uses 25 / 50 = 0.5 and produces [10, 20, 30, 40]. All original B/A ratios were 2; all scaled ratios are 1.

If the doubling arose entirely from a shared technical multiplier, that operation removes it in this idealized model. If all four features genuinely doubled per unit of the intended sample denominator, the same operation removes the biological change. The two numerical arrays alone cannot identify which explanation is correct. Information about sample input, appropriate standards, and the biology must supply that distinction.

Evaluate correction without rewarding overfitting

Plot feature responses against injection order and batch before and after correction. For a positive, ratio-scale response, one descriptive repeatability measure is CV (%) = 100 × sample standard deviation / mean. In invented QC responses [90, 100, 110], the mean is 100 and the sample standard deviation, using divisor n − 1, is 10; the CV is 10%. This describes those three values, not universal method acceptability. Precision depends on the measurement conditions. [6]

Reduced variation among the very QCs used to fit a flexible curve can merely show that the curve fits them. Where feasible, use withheld controls or another independent check. Inspect retained biological contrasts, concentration-dependent behavior, control failures, and residual order effects. Principal-component plots are useful diagnostics, but making batch clusters disappear does not alone prove that biological information was preserved.

If condition and batch are completely confounded, correction cannot discover their separate effects from those data alone. Return to experimental design rather than treating software output as evidence that the ambiguity vanished. Record model parameters and preprocessing order so the original matrix can be recovered.

Keep unavailable observations visible

Blank filtering, feature exclusion, drift correction, and imputation alter different parts of a dataset. A missing value is not automatically zero, and a signal absent from the pooled QC may still occur in a study sample. An imputed number is a model output rather than a new measurement. A primary proteomics benchmark found that imputation performance depends on workflow and evaluation task. [4]

Compare relevant conclusions with an unimputed or otherwise appropriate alternative, preserve missingness flags, and report why a handling strategy fits the study. For prediction, learn data-dependent transformations using training data within the evaluation design. Document the complete sequence of steps, not just the final algorithm name. [5]

Check your understanding

Does a pooled QC with low CV establish accurate concentrations?

No. It demonstrates consistency for the represented signals and conditions. Concentration accuracy requires suitable calibration and independent quantitative checks.

Should normalization be chosen because it yields more significant features?

No. Select it from a defensible measurement model and evaluate independent evidence. Optimizing the number of discoveries risks rewarding distortion.
