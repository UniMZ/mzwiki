Definition

An adjusted p-value expresses a test's result on the threshold scale of a specified multiple-testing procedure and hypothesis family. The method matters: Holm targets family-wise error, whereas Benjamini–Hochberg (BH) targets false discovery rate under suitable assumptions. R's p.adjust implements these and other procedures. Report the method and family, not just “corrected significance.” [1]

A simple example

Invented three-test family: sorted p-values [0.01, 0.04, 0.05] first give BH-scaled values [3 × 0.01 / 1, 3 × 0.04 / 2, 3 × 0.05 / 3] = [0.03, 0.06, 0.05]. Taking cumulative minima backward yields adjusted values [0.03, 0.05, 0.05]. All pass a prespecified ≤0.05 rule. The backward step is essential; multiplying each p-value by the number of tests is Bonferroni adjustment, not BH.

Common confusion

An adjusted p-value of 0.03 is not a 3% posterior probability that this particular finding is false. FDR is an expectation about a procedure's rejected set, not an individual correctness probability. [2] Nor does adjustment repair confounding, pseudoreplication, or invalid raw p-values.

BH supports independence or appropriate positive dependence such as PRDS, not arbitrary dependence merely because features are correlated. The Benjamini–Yekutieli modification is more conservative and addresses general dependence under its assumptions. [3]

“q-value” is not an unambiguous synonym. Storey-style q-values estimate a related minimum FDR-based significance measure, commonly with an estimated null proportion. Software sometimes labels BH-adjusted p-values as q-values; check the implementation and report the actual method. Neither quantity is a local posterior error probability. [4]

Check your understanding

May you correct only rows whose raw p-values are below 0.05?

No. Apply the procedure to the defined testing family, not a set preselected for small p-values.
