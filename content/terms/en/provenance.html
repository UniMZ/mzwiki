Definition

Provenance is information connecting a result to the entities, activities, and responsible agents involved in producing it. For MS, this includes sample and file relationships, acquisition, conversion, databases, analysis parameters, software versions, and subsequent edits. W3C PROV provides a general model for expressing such histories; it does not replace a mass-spectrometry data format. [1]

Preserve the route, not just the endpoint

Constructed example: a final peptide table came from a search of a converted spectral file against a particular database release. A useful record links the table to that search, its settings, the converted file, its converter settings, and the original acquisition. Saving only the final filename loses the transformations needed to interpret or repeat the result.

Common confusion

A checksum supports verifying file bytes; it does not prove correct sample attribution, valid identification, or identical downstream interpretation. A repository accession helps locate deposited material, but exact files and versions still matter. ProteomeXchange guidance distinguishes measurement data, results, and metadata for sharing. [2] Keep unavailable history explicitly unknown rather than reconstructing undocumented settings as if they were facts.
