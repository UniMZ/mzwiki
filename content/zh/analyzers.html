不同物理机制，相同坐标

质量分析器将离子运动与 m/z 联系起来，但它本身不能确定化合物身份。仪器常组合多种部件：四极杆选择前体，碰撞池使其碎裂，飞行时间或 Orbitrap 分析器测量产物离子。

对于每种分析器，可以先问三个问题：离子经历什么运动，测量什么信号，又如何把信号转换为 m/z？先看概览，再理解机制，最后比较性能。

比较分析机制

分析器物理原理需要注意
四极杆射频与直流电场使选定离子的运动轨迹保持稳定。可作为质量过滤器。隔离宽度和传输效率影响选择性与灵敏度。
飞行时间（TOF）受控加速后，飞行时间与质荷比相关。计时、初始能量分布、校准和离子光学影响峰宽与准确度。
射频离子阱电场约束离子，通过受控激发或排出来分析，也可进行多级碎裂。离子容量、空间电荷、扫描条件和可用质量范围很重要。

FT-ICR磁场中的回旋运动产生与质荷比相关的频率。磁场、瞬态信号时长和离子相互作用影响分辨本领。

IUPAC 对这些分析器类型作出了定义。[1] Makarov 的原始 Orbitrap 论文介绍了静电俘获与基于频率的质量分析原理。[2]

四极杆：利用运动稳定性过滤离子

四根杆电极围成离子通道。相对的两根杆连接同一电压；两组杆上施加符号相反的直流（DC）与射频（RF）交流电压组合。在给定设置下，某一 m/z 范围内的离子在两个横向方向上均保持稳定运动，因而能够通过；其他离子的运动幅度过大，无法传输。这检验的是电场中的运动，而不是识别化学物质身份。[4]

在 RF 频率固定的常规质量扫描中，仪器同时改变 RF 与 DC 的幅度，使可传输的范围沿选定区间移动。将检测器信号与变化的设置对应起来，即可形成质谱图。保持在选定设置则可进行选择离子监测。[5] 固定的隔离窗口可能同时通过多种离子；选中某个标称 m/z 并不能确定分子身份。

不能仅凭“四根杆”就判断其功能。仅射频四极杆可传输低 m/z 截止值以上较宽范围的离子，并不进行上述 RF/DC 窄带过滤。因此，离子导向器和碰撞池中的这类器件承担的任务不同。[6]

飞行时间：由到达时间换算 m/z

TOF 实验发射一个离子包，并记录离子到达检测器的时间。在起始条件受控时，较低 m/z 的离子先到达。脉冲确定计时起点；它可以来自脉冲式离子产生，也可以来自对已有离子束的脉冲提取。[7]

理想教学模型：假设初始动能可忽略，加速电势差的大小为 V，无场飞行路径长度为 L，离子以非相对论速度运动且不发生碰撞。令 M 为离子的实际质量，n = |z| 为电荷数的正值大小，e 为元电荷，u 为表示实际质量的道尔顿。谱图坐标数值为 x = M / (u n)；能量守恒给出 M v² / 2 = n e V。代入 τ = L / v 得到 τ = L √(u x / (2 e V))，因此 x ∝ τ²。经过相同 V 加速的离子获得相同的单位电荷能量，不一定获得相同的总能量。

构造的比例示例：若 x = 100 时，经修正的飞行时间 τ = 10 微秒，则同一理想装置在 x = 400 时给出 20 微秒，在 x = 900 时给出 30 微秒。m/z 增至四倍，飞行时间增至两倍。实际仪器的测量时间可能含有偏移：应使用 τ = t − t₀，不能直接把 t 代入。

真实离子包的初始位置、能量和发射时间均存在分布。反射器（reflectron）是一种静电离子镜：对于相同 m/z，能量较高的离子进入镜场更深、停留更久，从而补偿部分飞行时间差。[7] 实际离子光学与校准关系比直线路径教学方程更复杂；该方程不是通用的仪器校准公式。

射频离子阱：储存、选择、活化与排出

射频离子阱将离子限制在器件内一段受控时间。线性四极杆离子阱可改变俘获和激发条件，使不同 m/z 的离子依次排出并接受检测。它还可以隔离离子、使其活化、保留选定产物，再重复这一过程，实现 MSn。原始线性离子阱研究演示了这些操作。[8]

离子储存使同一器件内的一系列实验成为可能，但被储存的离子并非彼此独立。离子间的相互电排斥称为空间电荷效应；当离子群过于密集时，其运动会受到影响。[9] 因此，离子数量、扫描条件以及俘获和活化设置都应写入方法说明。

本节的“射频离子阱”指四极杆离子阱这一类。Orbitrap 和 FT-ICR 也会俘获离子，但下文基于频率的检测方式不同于质量选择性排出。

频率分析：记录反复的离子运动

运动的离子包会在附近电极上感应出微弱电信号。镜像电流测量在离子仍处于分析器内时记录该信号，不需要每个离子撞击检测器。这段时间记录称为瞬态信号。傅里叶变换分解出其中的频率分量，再通过校准关系将频率转换为 m/z。Orbitrap 与 FT-ICR 都采用这一基本流程。[10] [11]

Orbitrap：测量轴向振荡

离子在静电场中绕中心电极运行，同时沿其轴向振荡。用于质量分析的是轴向振荡频率，而非简单地测量绕电极转动的速率。在理想电场中，f = C / √x，其中 x 为 m/z 数值，C 由分析器电场与几何结构决定。[2]

构造示例：选取 C，使 x = 200 时 f = 100 kHz，则 x = 800 时 f = 50 kHz。因此 x = (C / f)²：m/z 越高，频率越低。这里选取的数值仅用于说明关系，不是某台仪器的指标。

FT-ICR：测量磁场中的运动

磁场使离子运动轨迹弯曲。对于在大小为 B 的均匀磁场中、垂直于磁场方向的理想非相对论自由回旋运动，将磁力与向心力相等可得 n e v B = M v² / r。结合 f_c = v / (2πr) 和前述定义，可得 f_c = e B / (2π u x)。在 B 固定时，无扰动回旋频率与 1 / x 成正比。

FT-ICR 通过激发使离子运动形成可测量的时域信号，再进行傅里叶分析。[11] 真实 ICR 池还使用俘获电场；通常检测到的约化回旋频率不同于理想的自由回旋频率。实际校准必须考虑真实测量条件。[12]

另一个独立的构造示例：选取 B，使 x = 200 时理想 fc 为 100 kHz，则 x = 800 时为 25 kHz。前面的 Orbitrap 示例下降至二分之一，而本理想 ICR 示例下降至四分之一。不同的指数关系会影响对不同质量范围内性能的理解。

观察时间只是采集时间的一部分

在有效、相干的信号能够持续时，观察越久通常越有利于区分相近频率。一个简单的数学尺度是未补零离散傅里叶变换的频率网格：若以采样频率 fs 记录 N 个样本，则 T = N / f_s，且 Δf_grid = f_s / N = 1 / T。0.10 秒记录对应 10 Hz 网格间距，0.20 秒记录对应 5 Hz。这里是网格间距，不是通用的半高全宽，也不保证两个峰能够分开。

在同一段记录后补零，可以加密计算得到的频率网格，却没有延长对离子的实际观察。信号衰减、噪声及处理方法仍影响最终峰形。在相同记录时长下，实际傅里叶处理也可能改变所报告的分辨本领；一项原始仪器研究展示了相位信息的重要性。[13]

瞬态信号时长也不同于离子累积时间和完整采集周期。装载、隔离、活化、读出及其他步骤均可能占用时间；某些仪器会使部分操作重叠进行。[13] 判断色谱峰被采样得是否足够密集时，应检查实际周期时间。

沿离子路径理解混合仪器

可将混合仪器的描述拆成一系列任务：产生离子 → 选择或传输离子 → 按需活化 → 测量所得离子。Q-TOF 或四极杆–Orbitrap 中的四极杆可选择进入的离子范围，后续分析器则测量实验产生的离子。因此，仅说“高分辨 MS/MS”并没有说明前体隔离窗口有多窄。选择到产物的流程见碎裂与串联质谱，术语见质量分析器。

计算示例：解读分辨率指标

某指标给出在 m/z 500 处，采用半峰全宽（FWHM）定义时 R = 50,000。令 x 为质荷比坐标数值，w 为同一坐标尺度上的轮廓峰宽，即扣除基线后两个半峰高交点之间的距离。于是 R = x / w，且 w = 500 / 50,000 = 0.010。R 无量纲；这里的峰宽是质荷比坐标差，不是以 Da 表示的中性质量。

FWHM 与两峰之间的谷高标准是不同的测量约定；若未说明定义及参考质荷比，单独的分辨率数值是不完整的。[1] 在此峰宽下，500 附近相差 0.004 的两个离子可能无法充分区分。500 / 0.004 = 125,000 只是给出一个峰宽等于峰间距的尺度，不能保证基线分离。峰形、相对强度和信号质量都很重要。

分辨本领、质量准确度与精密度

分辨本领关注峰宽或峰的分离。质量准确度关注接近参考值的程度；带符号的质量误差衡量某次具体偏差。精密度关注重复测量之间的一致性。即使峰很窄，校准与干扰仍会影响位置的可靠性。官方仪器指南解释了为什么应在明确条件下评价准确度。[3]

定义 xobs 为观测坐标，xref 为相同离子组成、电荷和同位素的参考坐标。则 error (ppm) = 10⁶ × (x_obs − x_ref) / x_ref。正值表示测量位置偏高。若将质子化离子与中性质量或错误同位素比较，所得准确度评价没有意义。

匹配窗口不是峰宽

给定以 ppm 表示的容差 t，以 xref 为中心的对称搜索窗口半宽为 δ = x_ref × t × 10⁻⁶。在 500 处，±5 ppm 表示 ±0.0025，即 499.9975–500.0025；在 1000 处，同一容差表示 ±0.0050。因此，固定坐标窗口和固定 ppm 窗口在不同位置的行为不同。

容差是一项分析决策，并不意味着所有通过窗口的匹配都正确。不能从显示的小数位数推断容差。应参考校准证据、合适对照及相关方法下的误差分布。单独的质心列表不保留测量 FWHM 所需的轮廓峰宽。参阅带注释的模拟例子，分别观察位置偏移与峰宽。

性能需要权衡

在傅里叶变换测量中，更长的瞬态信号通常有利于区分频率，但也消耗时间。LC 实验仍需对色谱峰进行足够密集的采样。因此，更高的标称分辨本领不一定是最优采集选择。

质量准确度关注相对于参考值的偏差；分辨本领关注峰的分离；灵敏度关注既定方法下分析物量与响应的关系；动态范围关注可用信号跨度。比较时应说明条件，而不是用一个指标给仪器排序。

理解检查

高分辨本领能排除共隔离前体吗？

不能。在高分辨产物测量之前，多个前体可能已经进入同一隔离窗口。产物分离能力有助于解释，但不能撤销已发生的混合碎裂。

TOF 中质量大一倍的离子一定更晚到达吗？

不一定。应比较 m/z，而不是只比较质量。在理想模型中，质量为 800 u、电荷数大小为 2 的离子，与质量为 400 u、电荷数大小为 1 的离子，都具有 x = 400；在所述条件下，它们的飞行时间相同。

显示的傅里叶频率网格密度翻倍，是否意味着观察时间翻倍？

不是。补零可以增加由同一段记录计算出的频率点数。真正更长的瞬态记录，需要在更长时间内获取额外的实测样本。

进一步学习

质心化、傅里叶处理、校准及峰拟合都可能改变最终峰列表。评价算法时应保留采集参数，并区分轮廓数据和质心数据。在某种分析器和处理流程上的基准结果，不一定能直接推广到另一种情况。
