一张记录的谱图可以有多个来源

质谱图记录一次采集中到达测量系统的离子，并不保证所有峰都来自同一化合物。在 GC-EI 中，共洗脱化合物可向同一扫描贡献碎片。谱图解卷积尝试利用离子强度随时间变化等额外结构，从测得的混合信号中重建组分贡献。模型峰提取是已有的 GC-MS 方法之一。[1]

这种重建属于推断，并非对已分离化合物的第二次测量。有用的结果应能在明确假设下解释观测信号，并在数据无法区分贡献来源时保留歧义。

区分两类常见混合问题

在常规 GC-EI 全扫描中，碎裂发生在离子源内，没有串联实验中的前体选择步骤。在 LC-MS/MS 中，一个隔离窗口可以传输多个随后共同碎裂的前体物种，它们的产物构成嵌合谱图。DDA 和 DIA 都可能发生这种情况；选择一个目标并不保证隔离纯度。[2]

LC-DIA 处理必须把产物离子证据与合理的前体候选及允许它们通过的窗口联系起来。MS-DIAL 的原始研究提供了针对小分子的色谱轨迹提取、模型峰构建和 MS/MS 重建实例。[3]GC-EI 和 DIA 可以利用相关的时间轮廓推理，但它们的采集约束和算法并不相同。

一个透明的混合模型

设想一张表，行是采集时间，列是 m/z 通道。每一列都是一条提取离子色谱图。一个简单模型把每条测量轨迹表示为缩放后的组分轮廓加上背景和误差：y(t) = aA(t) + bB(t) + background(t) + error(t)。

这里 A 和 B 描述随时间变化的形状；a 和 b 描述各组分在这一特定 m/z 通道中的贡献大小。不同通道具有不同的系数。在这个模型中，每个组分的相对离子模式在拟合区间内保持不变，信号近似线性相加，选定的轮廓能够充分描述洗脱事件。饱和、不断变化的干扰或错误估计的峰形都可能违反这些假设。

计算例子：分离一条共享离子轨迹

构造的无噪声例子：在三个等间隔时间点，无干扰的诊断通道给出组分轮廓 A = [1, 2, 1] 和 B = [0, 1, 2]，采用任意但固定的归一化。一条共享 m/z 通道的实测强度为 y = [3, 8, 7]。假设其背景为零，采样时间与轮廓时间对应。

第一个点满足 3 = a × 1 + b × 0，所以 a = 3。第二个点满足 8 = 3 × 2 + b × 1，所以 b = 2。第三个点用于检查结果：3 × 1 + 2 × 2 = 7。因此，两者的贡献分别为 3A = [3, 6, 3] 和 2B = [0, 2, 4]，相加后重现全部三个观测值。

对各 m/z 通道重复拟合，就能组合出每个组分的相对离子模式。系数并不自动等于浓度，因为它取决于轮廓归一化和仪器响应。三个点只是为了清楚展示算术，并非充分色谱采样的建议。真实数据需要处理噪声，并审查残差，即测量信号与拟合信号之差。

何时无法唯一分离

如果 B 与 A 的轮廓完全相同，模型变成 y = (a + b)A。对于 y = 5A，系数对 (3, 2)、(1, 4) 和 (5, 0) 都能完美拟合。仅凭时间轮廓无法从中作出选择。几乎相同的轮廓也可能使贡献估计不稳定：很小的测量变化就可能引起拟合系数的大幅变化。

具有区分力的离子、有独立依据的参考谱、另一个分离维度或新的测量，都可能增加约束。软件偏好某个答案，本身不是新的证据。检测到更多组分或得到更小的拟合误差，并不自动意味着化学重建更准确。

先审查重建，再审查鉴定

  • 检查采集：保留扫描时间、MS 级别、极性，以及 MS/MS 的隔离窗口和碎裂设置。比较在相容条件下采样的轨迹。
  • 检查轮廓：检查提出的诊断通道、共享离子、峰边界、背景及削顶。邻近区域的背景扣除通常无法去除强度随峰变化的共洗脱组分。[4]
  • 检查稳定性：检查是否存在有结构的残差，以及适度且有依据的设置调整是否改变组分谱图或归属。
  • 检查外部证据：在可获得时，比较标准品、空白和已知混合物。重建谱图的谱库匹配仍需要单独的证据评估。

保留原始扫描关联、提取轨迹、模型轮廓、软件版本、参数、重建谱图及不确定性标志。应单独验证定量面积，不要假定良好的重建就能保证无偏定量。对于 GC-EI，还应加入电子电离与保留指数中介绍的方法匹配保留证据。

检查理解

为什么一个共享碎片不必只属于 A 或 B？

两个组分都可能产生它。计算例子分配了双方的贡献，而非把整条测量轨迹归给一个组分。

零残差能否证明两个相同轮廓已被正确分离？

不能。多个系数对可以产生相同的拟合数据。拟合质量与解的唯一性是不同问题。

评估完整推断过程

把重建与特征检测、谱库检索和基准设计联系起来。应分别评估组分检出、谱图保真度、鉴定错误和定量偏倚；其中一项成功并不能证明其他项也成功。
