轮廓质谱

保留跨谱峰强度采样值的谱图表示，不意味着未经处理的检测器波形。

TERM ENTRY · OCT 2026
ENZH

含义

轮廓质谱用分布在谱峰坐标范围内的强度采样值表示一个峰，常见坐标为 m/z。PSI-MS 将它与质心质谱区分，后者为每个峰报告一个坐标与强度对。[1]“轮廓”描述的是表示方式，不是身份置信度，也不表示完全没有经过处理。

检查峰形，而不只看最大值

考虑五个连续坐标上的构造强度 [0, 2, 7, 3, 0]。最大值为 7，但周围数值还描述了不对称和宽度。把这个区域替换为单点，就省略了这些采样峰形。计算面积需要坐标间隔；五个索引等间隔的条目，并不能证明 m/z 值也等间隔。

轮廓表示不能保证什么

轮廓数据可能已经体现校准、平均、滤波或傅里叶变换。它不一定是检测器波形，也不一定保留了瞬态信号。采样和处理影响着可供检查的峰形。峰提取算法可以从插值后的轮廓估计位置，说明测得的采样值与衍生估计量不同。[2]使用轮廓证据评估重叠、截顶或分辨本领时，应保留来源及处理记录。

References & further reading

  1. HUPO-PSI. PSI-MS controlled vocabulary: peak picking, centroid spectrum, and profile spectrum.

    Official controlled vocabulary, inspected data version 4.2.2 (2026-09-18). Entries MS:1000035, MS:1000127, and MS:1000128 support representation boundaries; no universal centroid-intensity algorithm is inferred.

  2. OpenMS. PeakPickerHiRes class documentation.

    Official developer documentation inspected 2026-10-07; generated page dated 2026-09-30. Describes cubic-spline peak reconstruction, reporting its maximum, optional width information and applicable data assumptions. No parameter defaults or universal algorithm recommendation is prescribed.
