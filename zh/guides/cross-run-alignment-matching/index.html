Guide 32 · Computation

跨运行对齐与特征对应

区分时间坐标校正与匹配，检查有歧义的分组，并区分基于信号的缺峰回填、鉴定和统计插补。

FOUNDATIONAL GUIDE · OCT 2026
ENZH
Before you begin: LC-MS 特征检测与峰积分

共享一行就是提出对应关系

完成单次运行的特征检测后，每次运行都有自己的信号列表。建立矩阵时，必须决定哪些条目在不同运行间相互对应。这是新增的分析判断：一行包含三个面积，就意味着声称这些测量代表可比较的信号实体。整齐的矩形表格可能掩盖错误匹配。

应区分对齐与对应关系分析：前者把保留时间放到可比较的坐标系中，后者把跨运行的候选信号归为一组。xcms 文档将它们列为独立操作。[1] [2]这里的“特征组”指跨运行对应组，不是单次运行内的同位素或加合离子分组。

估计坐标映射，而非创造新测量

保留时间对齐估计一次运行的时间坐标如何对应参考坐标。一类方法使用证据充分的共同标志信号，另一类比较更广泛的色谱信号模式。xcms 提供了两类实现。有些流程需要先初步分组以估计校正，再重新分组；另一些流程可在峰检测前对齐。[1]不存在脱离具体算法的通用命令顺序。

参考运行不一定包含全部化学成分，也不一定没有误差。要问标志信号是否覆盖整个时间范围，以及是否代表可比较的信号。仅由中段数据支持的映射，在两端的依据较弱。应保留原始时间和拟合变换，使可疑校正能够追溯到实际采集的运行。

计算例子：恒定平移并不足够

构造的教学映射：三个可信标志信号在参考 A 中的时间为 [100, 300, 600] s，在运行 B 中为 [110, 320, 630] s，分别延后 10、20、30 s。假定在这些成对标志之间采用分段线性映射；这并不意味着三个标志足以支持真实实验。

对 B 中 215 s 的信号，在 B = 110 与 320 之间插值得到 A 轴上的时间：100 + (215 − 110) × (300 − 100) / (320 − 110) = 200 s。若只减去恒定的 10 s，则得到 205 s。两者相差 5 s，足以改变后续某些匹配判断。

在下一段，B = 475 s 映射为 300 + (475 − 320) × 300 / 310 = 450 s。坐标校正不会把先前测得的丰度变成新的浓度。如果软件同时对轨迹重新采样或重新积分，应分别记录这些操作及积分所使用的时间轴。

容差窗口只提出候选项

对应算法可以使用 m/z 与校正后的时间，并在可用时加入电荷、同位素结构、淌度或碎裂等证据。xcms 文档展示了基于密度和邻近程度的分组，并明确列出影响结果的设置。[2]落在窗口内只表示符合该规则，不能证明候选唯一，也不能确定化学身份。

假设的歧义匹配：运行 A 有一个 m/z 500.2000、参考时间 200 s 的信号。运行 B 有两个候选，分别为 500.2010/201 s 和 500.2015/202 s。相对于 A，m/z 差异约为 2.00 与 3.00 ppm。两者都通过虚构的 ±5 ppm 和 ±4 s 限值。这些只是教学设置，不是经验证的推荐值。

最近邻规则可能选中第一个候选，但排序本身不是证明。应检查 B 是否把一个峰拆开、附近是否有两个独立物种洗脱，以及附加证据能否区分它们。无法解决时应保留歧义。扩大窗口可能减少空单元格，却同时引入错误对应关系。

检查组内实际包含什么

检查同一运行是否有多个成员进入一组、时间或 m/z 分布是否异常宽，以及峰形不同的信号是否被合并。也要检查看似应当对应却仍被分开的信号。算法可能选一个成员、合并多个成员，或保留冲突；应记录规则，不能让导出的矩阵悄悄决定。

特征出现频率规则会影响哪些组被保留。要求每个样本都检测到信号，可能丢掉真实的条件特异性信号；过于宽松又可能保留偶发噪声。选择标准前，应明确预期比较并检查对照。在 xcms 的一种密度分组规则中，出现比例要求作用于至少一个样本组，而不一定是所有样本的整体比例。[2]

利用原始信号重新检查空单元格

缺峰回填可针对某次运行中没有检测到组成员的位置，返回预期的 m/z–时间区域提取丰度。它不同于只用矩阵中其他数值替换空单元格。xcms 用专门标志记录回填结果。[3]

构造的例子：某组在 A、B 运行中的检测面积分别为 100、120，C 没有通过检测的信号。重新提取 C 的预期区域得到面积 12。这个数来自 C 自己的信号；替换为平均值 110 则来自 A、B。两种操作都不能独立确定 C 中的分子身份。背景或干扰信号也可能产生非零积分。

应审查提取边界、质量一致性、轨迹形状和空白表现。保持“初次检测”“回填”“尚未解决”和“不可用”等状态可区分。没有可用信号的区域不必变成零；xcms 明确允许保留未回填的缺失结果。[3]有数值的单元格更多，本身不是测量更好的证据。

评价矩阵背后的判断

比较对齐前后的标志残差和代表性轨迹。条件允许时，检查未参与拟合的可靠标志。注意良好平均表现掩盖的局部失败、不合理变换，以及对小幅参数变化异常敏感的结果。匹配质量应独立于对齐图是否美观来评价。

保存每组的运行级成员关系、备选项或冲突、校正模型、原始和调整后的坐标，以及提取标志。将化学鉴定证据与这些信号关联分开；mzTab-M 明确区分特征记录与鉴定证据记录。[4]这样后续修正可被审计，而不会悄悄改写一行的含义。

检查理解

校正后的保留时间相同，是否证明两个信号匹配？

不能。变换只对齐坐标，可能仍有多个相容信号。匹配需要证据及明确的冲突处理规则。

把 C 的空单元格回填为面积 12，是否鉴定了化合物？

没有。这只是从预期区域提取信号。鉴定需要独立证据，回填数值也仍需质量评价。

为什么不选择让缺失单元格最少的参数？

过宽的匹配和提取区域可能引入错误信号或背景。完整性必须与对应关系及测量质量一起评价。

References & further reading

  1. xcms. Alignment: retention time correction methods.

    Official developer documentation inspected 2026-10-07, showing version 4.11.4. Describes signal-pattern and peak-group alignment methods with different input dependencies. Teaching mappings are original arithmetic examples, not recommended landmark counts.

  2. xcms. Correspondence: group chromatographic peaks across samples.

    Official developer documentation inspected 2026-10-07, showing version 4.11.4. Separates correspondence from alignment and describes grouping criteria, including a detection fraction within at least one sample group. Used as an implementation example, not a universal feature definition.

  3. xcms. Gap filling: fillChromPeaks.

    Official developer documentation inspected 2026-10-07, showing version 4.11.4. Supports re-extraction from feature-informed m/z–time regions, is_filled flags, and remaining missing results where no signal exists. Does not establish new molecular identifications.

  4. HUPO-PSI and MSI. mzTab-M 2.0 metabolomics results specification.

    Official released format specification. Sections 5.2 and 5.4 distinguish samples/assays/runs and missing-data encoding; sections 6.3–6.5 distinguish molecule summaries, features, and identification evidence. A format declaration does not verify biological independence or determine the missing-data mechanism.
