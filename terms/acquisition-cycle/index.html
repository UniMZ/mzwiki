Acquisition cycle

A repeated measurement schedule whose duration determines when a channel is revisited.

TERM ENTRY · OCT 2026
ENZH

Definition

An acquisition cycle is a repeated measurement sequence. Its cycle time is the elapsed time from a defined point in one sequence to the same point in the next. For windowed DIA, an especially useful definition is the time until the same precursor window is measured again. [1] State which event is your reference when a method has several interleaved experiments.

A cycle can contain one spectrum or many. DDA can limit the number of dependent scans or allocate a time budget, so a method label alone does not specify every actual cycle duration. [2]

A simple example

Constructed serial schedule: one 0.20 s survey, twenty 0.04 s window measurements, and 0.20 s additional overhead occupy 0.20 + 20 × 0.04 + 0.20 = 1.20 s. Assume no overlap between these blocks. There are 21 spectra per cycle, but only one measurement of any particular window.

A consistently defined 12 s peak width gives 12 / 1.20 = 10 approximate opportunities for that window. This ratio is not an exact count, an identification count, or a universal quality threshold. Sampling phase and peak-width convention matter. The same planning ratio is used in targeted-method timing. [3]

Common confusion

MS2 describes an analysis stage, not cycle two. A scan's transient or accumulation setting is not necessarily the complete cycle time: some operations overlap, while others add overhead. Check the instrument's actual timestamps. [4] In DDA, a short cycle also does not guarantee that every precursor is selected for MS/MS in each cycle.

References & further reading

  1. Gillet et al. (2012). Targeted data extraction of the MS/MS spectra generated by data-independent acquisition: a new concept for consistent and accurate proteome analysis. Molecular & Cellular Proteomics 11, O111.016717.

    Primary study underlying SWATH-style DIA extraction. DOI: 10.1074/mcp.O111.016717.

  2. Thermo Fisher Scientific. Orbitrap Tribrid Apex Small Molecule Method Editor Help: Data-dependent properties pane.

    Official explanation of Top N as an upper number of dependent scans and cycle-time-limited acquisition as a different scheduling mode. No default settings or product-performance claims are transferred.

  3. SCIEX. How to choose the appropriate dwell time/cycle time in an MRM and sMRM method to get enough points per chromatographic peak.

    Official timing equations for dwell, pause, active transitions, and cycle time. Used for the simplified serial model; platform-specific defaults and universal sampling thresholds are excluded.

  4. Michalski et al. (2012). Ultra High Resolution Linear Ion Trap Orbitrap Mass Spectrometer (Orbitrap Elite) Facilitates Top Down LC MS/MS and Versatile Peptide Fragmentation Modes. Molecular & Cellular Proteomics 11, O111.013698.

    Primary instrument study showing that field geometry and phase-aware Fourier processing influence resolving power at a given transient duration and that parallel acquisition affects cycle time. DOI: 10.1074/mcp.O111.013698. Used for those dependencies, not product comparisons.
